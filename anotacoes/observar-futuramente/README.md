# observar-futuramente/

Decisões conscientes de **não fazer algo agora** — não porque não importa, mas porque não vale o esforço no volume de uso atual. Cada arquivo aqui tem: o que foi decidido, por que, e **a condição concreta que deve disparar a revisão** (não "quando crescer", mas um número/sinal específico).

Diferente de `anotacoes/urgente/` (que é "olha isso antes do próximo deploy"): aqui é "não é urgente, só não esquecer de checar de novo quando as condições mudarem".
